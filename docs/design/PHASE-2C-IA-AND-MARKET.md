# Phase 2C information architecture and market specification

## Live navigation

- Properties: private portfolio, off-plan, advisory services.
- Explore: communities, commercial developers, Dubai guides.
- Intelligence: market overview, calculators, journal.
- Property data: public DLD directory, developers, projects, brokers, offices,
  licences and permits.
- DLX/footer: about, team, contact and privacy.

Buy, rent, payment-plan opportunities, transaction, price, rent/yield and comparison
destinations remain in the future route map but are not linked until they contain
useful, source-backed content. Global search routes only to the server-side public DLD
search contract; no browser component may query internal directory tables.

## Homepage change

Before: cinematic positioning, philosophy, tool and market modules before direct
discovery. After: one positioning hero followed immediately by official-data search
and live property/off-plan/community routes. Private inventory and the server-gated
concept state remain intact; a contextual human/AI close preserves source and intent.

## Directory change

Before: the same photographic hero repeated on list and detail pages. After: compact
paper introduction, bilingual/exact-number search, category navigation, sticky mobile
controls, structured identifiers, source date, unmatched-relation behavior and a
dedicated independence notice. The public server functions and privacy boundary are
unchanged. Richer grouping or facets belong in a later additive public API contract.

## Market intelligence components

The production language is a source-aware shell, never a dashboard of examples:

1. `MarketHeadlineIndicators`: value, unit, period, source date and sample size.
2. `TransactionTrend`: count/value switch with frequency and suppressed-small-sample state.
3. `PriceTrend`: median price/sq ft, property type and distribution warning.
4. `MixComparison`: ready/off-plan and apartment/villa shares with denominator.
5. `RentYield`: observed rent, price basis, gross/net definition and date alignment.
6. `CommunityComparison`: consistent period, type and minimum sample threshold.
7. `MethodologyNotice`: source, transformation, revision and known limitations.

Unavailable sections say analysis is being prepared. Synthetic chart data may appear
only behind the existing server-side demo-host gate, labelled “synthetic preview”, with
`noindex,nofollow`; the preferred Phase 2C implementation is to show no sample numbers.

## SEO/AEO behavior

Templates retain unique `.com` canonicals, server-rendered headings, breadcrumbs,
visible source/update language and structured data that mirrors visible facts. Demo
projects remain noindex. Official records canonicalize to `/directory`; future real
commercial projects canonicalize to `/off-plan`. Thin future routes are not generated.
