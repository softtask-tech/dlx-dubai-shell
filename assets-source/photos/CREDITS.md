# Photography sources

The originals are not committed: they are 40MB of 3 to 9 megapixel JPEGs, and
what the site serves is the optimized set in `public/photos`, which is. This
file is how they are recovered.

Every image below is from Pexels, under the Pexels licence (free for commercial
use, no attribution required). Attribution is recorded anyway, because knowing
where an asset came from is the difference between an asset and a liability.

Drop the originals back into this directory under the slug in the first column,
then run `npm i -D sharp && node scripts/build-photos.mjs`.
